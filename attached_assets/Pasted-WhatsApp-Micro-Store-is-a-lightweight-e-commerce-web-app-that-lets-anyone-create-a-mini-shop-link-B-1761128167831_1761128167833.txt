WhatsApp Micro-Store is a lightweight e-commerce web app that lets anyone create a mini-shop link.
Buyers browse a catalog, add items to a cart, and with one tap the app opens WhatsApp with a pre-filled order message (and optional payment link).
It works globally and requires no new messaging tools or automation.

Built with Next.js 14, TypeScript, Tailwind CSS, Supabase, and optional Stripe / Razorpay integration.

🚀 Workflow / How it Works
1️⃣ Seller creates a store

Visits the site → clicks Sign In / Sign Up (email OTP via Supabase Auth).

The dashboard auto-creates their first store.

They fill store info: name, WhatsApp number, currency, logo/banner.

They add products: photo, title, price, stock.

The app stores everything in Supabase Postgres and uploads images to Supabase Storage.

Result:
They get a shareable link —
https://microstore.repl.co/<store-handle>
Example: https://microstore.repl.co/demo-bakes

2️⃣ Customer orders from the storefront

Opens the store link.

Adds one or more products to a cart (client-side React state).

Fills a small checkout form (name, phone, address, notes).

Presses “Order on WhatsApp.”

The app then:

Creates a lightweight order record in the database.

Optionally generates a payment link (Stripe or Razorpay).

Builds a WhatsApp URL:

https://wa.me/<seller_number>?text=
Hello, I'd like to order:

1) Chocolate Croissant ×2 — ₹160
2) Almond Tart ×1 — ₹120
Total: ₹280
Name: John Doe
Address: Noida
Payment Link: <URL>


Redirects the buyer to that WhatsApp link.

The buyer simply hits Send.

3️⃣ Seller receives the order in WhatsApp

The seller sees a nicely formatted message with all details.

They confirm stock, adjust if needed, and send pickup/delivery info.

If payments are enabled, they track “paid” orders in the dashboard.

⚙️ Tech Stack Summary
Layer	Tool
Front-end	Next.js (App Router + Tailwind)
Auth	Supabase Auth (Email OTP / Google)
Database	Supabase Postgres (stores, products, orders)
Storage	Supabase Storage (private bucket for images)
Payments (optional)	Stripe / Razorpay Payment Links
Hosting	Replit / Vercel
Messaging	Native WhatsApp wa.me links (no bot API)
PWA Support	Manifest + Service Worker (installable app)
🔁 Data Flow Diagram (text version)
Buyer → Storefront → Cart → Checkout → /api/orders
     → (optional) /api/payment-link → WhatsApp prefilled message
     → Seller WhatsApp Chat ← Payment link / confirmation

💡 Why it’s useful

No need for sellers to manage heavy e-commerce platforms.

Customers trust WhatsApp, so conversion is high.

Works even on basic phones or low bandwidth.

Global reach — any seller with WhatsApp can use it.

🧱 Typical File Structure
app/
 ├─ page.tsx                     → landing
 ├─ auth/
 │   ├─ page.tsx                 → magic link sign-in
 │   └─ callback/page.tsx        → session exchange
 ├─ dashboard/                   → store & products management
 ├─ [handle]/page.tsx            → public storefront
 └─ [handle]/checkout/page.tsx   → checkout → WhatsApp handoff
lib/                             → Supabase clients (server/browser)
components/                      → CartProvider, ProductGrid, CheckoutForm, etc.
supabase/migrations/             → tables, RLS policies, seed data

🔑 Replit Instructions (simplified)

Import repo → open in Replit.

Add secrets in Tools → Secrets:

NEXT_PUBLIC_SUPABASE_URL=…
NEXT_PUBLIC_SUPABASE_ANON_KEY=…
SUPABASE_SERVICE_ROLE_KEY=…
STRIPE_SECRET_KEY=… (optional)
STRIPE_WEBHOOK_SECRET=… (optional)
RAZORPAY_KEY_ID=… (optional)
RAZORPAY_KEY_SECRET=… (optional)
APP_URL=https://<your-repl>.repl.co


Run:

npm install
npm run dev


Open Preview →

/ → landing

/auth → sign in

/demo-bakes → sample store
