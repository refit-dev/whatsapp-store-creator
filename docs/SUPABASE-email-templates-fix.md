# Supabase Email Template Fix

## Issue

The magic link email template is using a hardcoded Replit URL instead of the dynamic Site URL variable.

## Solution: Update Email Templates in Supabase

### Step 1: Access Email Templates

1. Go to **Supabase Dashboard**
2. Navigate to **Authentication → Email Templates**
3. Select **Magic Link** from the template list

### Step 2: Replace the Template

Replace the current template with this corrected version:

---

## ✅ Corrected Magic Link Template (Recommended)

```html
<h2>Magic Link</h2>

<p>Follow this link to login:</p>

<p><a href="{{ .ConfirmationURL }}">Log In</a></p>

<p>Or copy and paste this URL into your browser:</p>

<p>{{ .ConfirmationURL }}</p>
```

**Why this works:**

- `{{ .ConfirmationURL }}` is automatically generated by Supabase
- It uses your configured Site URL (https://watzy.app)
- Includes the proper token hash and type parameters

## 📧 Other Email Templates to Check

While you're in the Email Templates section, also verify these templates use `{{ .ConfirmationURL }}` or `{{ .SiteURL }}`:

### 1. **Confirm Signup**

```html
<h2>Confirm your signup</h2>
<p>Follow this link to confirm your user:</p>
<p><a href="{{ .ConfirmationURL }}">Confirm your email</a></p>
```

### 2. **Invite User**

```html
<h2>You have been invited</h2>
<p>You have been invited to create a user on {{ .SiteURL }}.</p>
<p><a href="{{ .ConfirmationURL }}">Accept the invite</a></p>
```

### 3. **Reset Password** ⚠️ IMPORTANT

```html
<h2>Reset Password</h2>
<p>Follow this link to reset your password:</p>
<p><a href="{{ .ConfirmationURL }}">Reset Password</a></p>
```

**CRITICAL:** For password reset to work, you must configure the redirect URL in Supabase:

1. Go to **Authentication → URL Configuration**
2. Set **Redirect URLs** to include: `https://watzy.app/auth/reset-password**`
3. The `{{ .ConfirmationURL }}` will automatically append `#access_token=...` which our handler processes

### 4. **Change Email**

```html
<h2>Confirm Change of Email</h2>
<p>Follow this link to confirm the update of your email:</p>
<p><a href="{{ .ConfirmationURL }}">Change Email</a></p>
```

## 🔍 Available Supabase Email Variables

These variables can be used in your templates:

| Variable                 | Description                      | Example                                         |
| ------------------------ | -------------------------------- | ----------------------------------------------- |
| `{{ .ConfirmationURL }}` | Full confirmation URL with token | `https://watzy.app/auth/confirm?token_hash=...` |
| `{{ .Token }}`           | Raw token value                  | `abc123...`                                     |
| `{{ .TokenHash }}`       | Hashed token value               | `fde8d24f...`                                   |
| `{{ .SiteURL }}`         | Your configured Site URL         | `https://watzy.app`                             |
| `{{ .Email }}`           | User's email address             | `user@example.com`                              |
| `{{ .Data.xxx }}`        | Custom metadata (if set)         | Varies                                          |
